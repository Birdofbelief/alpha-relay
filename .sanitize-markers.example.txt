# 自定义指纹清单 —— 格式示例（**本文件是入库的，别往里面写私密内容**）
#
# 扫描器的第二类规则跑的是**你自己提供的**正则清单，而不是任何内置的
# 「策略特征」列表。理由见 docs/SANITIZATION.md 第四节：
# 一条指纹规则必须写明它要抓什么，而公开仓库里那份规则清单本身就会成为泄漏点。
#
# 用法：**另建**一个 `.sanitize-markers.txt`（同目录）填你自己的规则 ——
#       那个文件名已被 .gitignore 挡住，不会进版本库。
#       直接照抄这份只会得到下面三条示例规则。
#       用 `SC_MARKER_FILE` 环境变量可以指向别处的清单。
#
# 格式：每行一条 —— 正则 + **制表符** + 类别标签。
#   · `#` 开头是注释，空行忽略
#   · 制表符是**强制**的。分隔符被打成空格时，正则照样编译得过
#     （空格在正则里只是普通字符），只是永远匹配不到任何东西 ——
#     这种失效从输出上完全看不出来。所以「某行没有制表符」被判为
#     **整轮作废**（退出码 2），不是跳过那一行。
#   · 同一类静默失效还有两种，处理方式一样：正则编译不过 → 作废；
#     `# expect: N` 与实际条数对不上 → 作废（用来发现规则被删掉）。
#
# expect: 3
INT-\d{6}	内部工单编号
\b[a-z0-9-]+\.corp\.example\.internal\b	仅内网可见的域名
\b(?:ACME|CONTOSO)_INTERNAL_[A-Z]{2,}\b	内部代号
